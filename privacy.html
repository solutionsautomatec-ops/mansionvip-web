Política de privacidad de mansionvip

Última actualización: noviembre de 2026.

Qué hace la aplicación

mansionvip es una herramienta de uso personal. Usa la API de YouTube (permiso youtube.upload) únicamente para subir videos al canal de YouTube de la cuenta que la autoriza.

Datos que se acceden y guardan

La aplicación no recopila datos personales de otras personas. Guarda solo un token de autorización de Google en el equipo o servidor de su propietario, para poder subir videos. No se lee, descarga ni modifica ningún otro dato de la cuenta de YouTube o de Google.

Con quién se comparten los datos

No se venden, comparten ni transfieren datos a terceros. El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El propietario puede retirar el permiso en cualquier momento desde myaccount.google.com/permissions.
